# 项目架构说明

## 📐 整体架构

这是一个**前后端分离**的学生信息管理系统，采用**三层架构**：

```
┌─────────────────────────────────────────────────────────┐
│                    客户端层                              │
├──────────────────┬──────────────────┬──────────────────┤
│  Web前端         │  Android应用      │  其他客户端      │
│  (React + Vite)  │  (Kotlin)        │  (iOS/其他)      │
└────────┬─────────┴────────┬─────────┴────────┬─────────┘
         │                   │                  │
         └───────────────────┴──────────────────┘
                            │
                    HTTP/RESTful API
                            │
         ┌──────────────────┴──────────────────┐
         │          后端服务层                    │
         │    (Spring Boot + MySQL)              │
         └──────────────────┬───────────────────┘
                            │
                    JDBC/JPA
                            │
         ┌──────────────────┴───────────────────┐
         │          数据持久层                    │
         │         (MySQL 数据库)                │
         └──────────────────────────────────────┘
```

---

## 🛠️ 技术栈详解

### 后端层

**框架：** Spring Boot 4.0  
**语言：** Java 17  
**数据库：** MySQL 8.0  
**ORM：** Spring Data JPA  
**API文档：** Swagger/OpenAPI  

**架构模式：**
- Controller 层：处理HTTP请求
- Service 层：业务逻辑处理
- Repository 层：数据访问

---

### 前端层（Web）

**框架：** React 18.2  
**构建工具：** Vite 5.0  
**HTTP客户端：** Axios  
**语言：** JavaScript (ES6+)  

**注意：** 前端使用的是 **React**，不是 Vue

---

### 移动端（Android）

**语言：** Kotlin  
**HTTP客户端：** Retrofit 2.9  
**架构模式：** MVVM (ViewModel + Repository)  
**异步处理：** Coroutines + StateFlow

## 🔄 数据流程

```

    ↓

    ↓
HTTP请求 (Axios)
    ↓
```

## 🎯 项目特点

### 1. 前后端分离

- **后端**：提供 RESTful API，不关心前端技术栈
- **前端**：可以是 Web（React）、Android、iOS 等任意客户端
- **通信**：通过 HTTP/JSON 进行数据交换

### 2. 统一API接口

所有客户端（Web、Android、iOS）都调用相同的后端API：
- `GET /api/student` - 分页查询
- `GET /api/student/search` - 搜索
- `POST /api/student` - 添加
- `PUT /api/student/{id}` - 更新
- `DELETE /api/student/{id}` - 删除

### 3. 移动端优化

- **分页查询**：避免一次性加载大量数据
- **统一响应格式**：便于客户端统一处理
- **CORS跨域**：支持多端访问

## 📱 多端支持

### Web端（React + Vite）

- **访问方式**：浏览器打开 `frontend/index-standalone.html`
- **或运行开发服务器**：`npm run dev` → `http://localhost:3000`
- **功能**：查看、添加、编辑、删除学生

### Android端（Kotlin）

- **访问方式**：Android Studio 运行应用
- **功能**：分页加载、下拉刷新、上拉加载更多、搜索、删除

### 其他客户端

- **iOS**：可以使用相同的API接口
- **Postman**：可以测试API接口
- **Swagger**：可视化测试接口

## 🔌 API接口

### 基础接口

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/student/all` | 获取所有学生 |
| GET | `/api/student/{id}` | 获取学生详情 |
| POST | `/api/student` | 添加学生 |
| PUT | `/api/student/{id}` | 更新学生 |
| DELETE | `/api/student/{id}` | 删除学生 |

### 移动端专用接口

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/student?page=0&size=10` | 分页查询 |
| GET | `/api/student/search?keyword=xxx` | 搜索 |
| POST | `/api/student/{id}/avatar` | 上传头像 |

## 🎯 总结

**您的理解基本正确，但有一个小修正：**

✅ **后端**：Spring Boot + MySQL  
✅ **前端**：React + Vite（不是 Vue）  
✅ **Android**：Kotlin + Retrofit  
✅ **功能**：通过 Android Studio 模拟器访问和操作  

**项目定位：**
- 这是一个**移动端后端API服务**项目
- 专门为移动端（Android/iOS）设计
- 同时提供 Web 前端作为演示
- 所有客户端共享同一套后端API
